# 未翻译聊天采集

用于把游戏里仍然显示英文的聊天文本收集起来，补进译名库。首次启动会显示数据与隐私说明，同意后进入游戏；该功能默认开启，可随时关闭。

## 打开与关闭

两种方式，效果相同：

- 游戏内 `/sapphire` 打开设置，在「高级设置」里切换「聊天漏译采集」。
- 命令：`/sapphire capture on|off|status|flush|upload`。

打开后，进入 SkyBlock 并确认环境生效时开始记录；离开服务器或退出游戏时结束本次会话。

## 记录什么

- 只记录**仍然是英文**的聊天行。已经译成中文的行、带链接的行不会写入。
- **不记录任何玩家消息**：普通聊天（签名聊天消息直接排除）、组队（Party）、公会（Guild）、Co-op、私聊（From/To/PM）、以及带 `[VIP]`/`[MVP+]` 等称号前缀的玩家发言都会过滤。
- `[NPC]`、`[BOSS]` 对话仍然会记录（这些是翻译目标）。
- 行内保留颜色与格式代码（`§7`、`§e§l` 等），格式与现有译名库一致，方便直接转成 `chat.json` 规则。
- 同一行只记一次；数字不同的同模板行按模板去重。

文件按会话生成，内容只含文本；文件名带游戏名和日期，便于区分会话：

```
untranslated-<用户名>-<yyyyMMdd>-<编号>.txt
untranslated-ESN17_OwO-20261111-1.txt
```

默认写入 `D:/Sapphire-source`，可在 `config/sapphire/config.json` 的 `chatCaptureDirectory` 修改。

## 物品与菜单漏译（只存本地）

「高级设置 → 收集未翻译文本」同样默认开启：确认处于 SkyBlock 后，把物品描述、菜单等漏译文本按 ID 去重记录到 `config/sapphire/untranslated/` 下的 JSON，受条数与磁盘上限约束。这部分只保存在本机，不会上传；可用 `/sapphire untranslated on|off|status|export|clear` 管理。

## 上传与删除

- 每 5 分钟或累计 200 行会把当前文件上传一次并开始新文件，避免崩溃或直接关闭窗口时丢数据。
- 离开服务器、退出游戏、直接关闭 Minecraft 窗口时都会上传剩余记录（含 JVM 关闭钩子）。
- 上传成功后**删除本地文件**；上传失败则保留，下次启动自动补传。
- 单个文件上限 5000 行 / 1 MiB，服务器端上限 2 MiB。

## 服务器

- 管理员在 https://sapphire.esn17cabin.club/untranslated/ 查看、下载、删除记录；普通账号与游客看不到内容。
- 上传使用令牌：服务器端文件 `/www/sapphire-private/state/untranslated-token.txt`，客户端填在 `config/sapphire/config.json` 的 `chatCaptureToken`。
- 轮换令牌：替换服务器文件内容后，更新客户端配置即可，旧令牌立即失效。
- 部署脚本：`tools/` 之外的 `deploy_untranslated.py`（本机脚本）负责写入页面、创建令牌并更新 nginx 的 `/untranslated/` 路由。

## 译文反馈

玩家发现译文有偏差或前后不一致时，可以在游戏里直接反馈：

- 入口：`/sapphire` 设置首页的「反馈译文问题」卡片，或命令 `/sapphire feedback` 打开反馈窗口；填写问题后点「发送反馈」。
- 反馈内容只有你填写的这段文字，**不附带玩家名、时间、界面标题或版本**；文件名 `feedback-anon-<编号>.txt`。
- 与聊天采集共用同一个上传令牌和服务器目录；管理员在同一个页面（https://sapphire.esn17cabin.club/untranslated/）查看、下载、删除。
- 上传失败时窗口会显示原因，内容仍留在输入框里，可重试。

## 实现位置

- `src/main/java/com/sorakoi/sbtranslate/collection/ChatCapture.java`：采集、写文件、上传、删除；`uploadText` 同时供反馈使用。
- `src/main/java/com/sorakoi/sbtranslate/collection/FeedbackSender.java`：反馈内容与文件名、上传重试。
- `src/main/java/com/sorakoi/sbtranslate/client/FeedbackScreen.java`：游戏内反馈窗口。
- `Sapphire.java`：会话开始/结束、退出钩子、启动补传、命令注册。
- `ChatDisplay.java`：在聊天行确认未命中词典时交给采集。
- `SapphireConfig` / `SettingsCatalog`：开关与路径、令牌配置。
- 服务器：`server/public/untranslated/index.php`、`server/sapphire.nginx.conf`。
- 测试：`src/test/java/com/sorakoi/sbtranslate/collection/ChatCaptureTest.java`（含可选的真实上传测试，需 `SAPPHIRE_CAPTURE_LIVE=1` 与 `SAPPHIRE_CAPTURE_TOKEN`）；`runClient -PcaptureSmoke=<properties>` 会跑一次真实上传冒烟。
