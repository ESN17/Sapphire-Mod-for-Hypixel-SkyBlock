# 附加技能、钻头配件和符文

本次检查依据用户截图、本地 NEU 英文物品记录和 2026-10-17 查阅的资料。译文中的伤害、传送距离、持续时间、燃料容量等均取自实际提示框，不在客户端重新计算，也不使用参考记录里的固定数字。

## 问题与处理

- Hyperion 基础词典不含安装卷轴后出现的 Wither Impact。补充“卷轴技能”“凋零冲击”，以及单独安装聚爆、暗影扭曲、凋零护盾时的技能说明。支持 Necron 之刃及 Hyperion、Astraea、Scylla、Valkyrie。
- 钻头配件安装后仍然属于钻头物品 ID。将 14 种可安装配件的标题和效果加入共享提示框词典，支持燃料罐、引擎和五种哥布林煎蛋卷；保留容量、百分比、属性图标和颜色。
- 独立符文使用 `RUNE` 或 `UNIQUE_RUNE`，类型和等级另存在 `ExtraAttributes.runes` 中。按此数据解析为 NEU 的 `类型_RUNE;等级`，支持现有 68 类、142 个等级版本。NEU 菜单中已经展开的符文 ID 同样支持。装备上的符文不会改变装备自身 ID。

## 数据与复现

共享条目：`translations/tooltip-paragraphs.json`。安装数据脚本：`tools/attachment_tooltip_data.py`。修改前备份：`translation-state/attachments/backup`。测试样本仅提取 NEU 公开的名称与描述，不包含皮肤签名或玩家资料。

运行 `gradlew.bat build` 执行构建和回归测试；使用 `gradlew.bat runClient -PsapphireSmoke -PsapphireSmokeDir=build/sapphire-attachment-smoke-20261017` 运行离线客户端检查。

## 2026-10-17 追加修复

英文预览改为按住左 Ctrl 或右 Ctrl，松开恢复中文。Shift 单独按下继续显示中文，不拦截其他 Mod 的按键。

增加实际服务器使用的钻头配件别名（包括 Sunny Side Goblin Egg Part、Titanium Drill Engine），以及 Pristine、Block Fortune、带累计次数的附魔名。挖掘时运、采矿智慧和采矿扩散说明兼容数字紧邻图标的形式；数字与图标各自的样式随原文复制。

逐项扫描当前 NEU 数据：同类物品标记确认 Undead 和 Arachnal 两种，分别译为“此物品属于亡灵类”和“此物品属于蛛类”，保留图标与感叹号。Undead 在当前字典中有 50 件物品，Arachnal 有 23 件；旧图标与私用区新图标都覆盖。另处理使用后消耗、最终形态、旧物兑换说明。未确认的新类型保留原文，不自动猜测类别。

Shiny 译为“闪耀”，单独保存在 name-modifiers.json；与洗练名分段翻译。品质行兼容 SHINY 前缀。验证包括凋灵套装及四种进阶套装、Necron 柄、未完型的Necron之刃和四神剑，保留染色装饰、升星与大师星。
