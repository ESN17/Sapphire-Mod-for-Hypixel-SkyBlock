# 右侧计分板翻译准备与覆盖范围

核对日期：2026年10月17日。

## 地名来源与计数

旧官方 Wiki 已关闭，入口跳转至[官方公告](https://hypixel.net/threads/end-of-the-official-hypixel-wiki-july-2026.6112020/)。本轮采用迁移后的社区 Wiki [地点总表](https://hypixelskyblock.minecraft.wiki/w/Locations)和[地点分类](https://hypixelskyblock.minecraft.wiki/w/Category:Locations)，分类第二页也已读取。

- 总表提取出 **315 个不同显示名**，含旧区域及尚未发布的区域；这不是当前可进入区域数量。
- 分类有 **339 个页面**，包含同名区域的消歧页面、讨论页和非单一地点的说明页，不能直接当作游戏区域数量。
- 合并补充后，词典有 **344 条地名与别名**，覆盖总表全部显示名及分类中的地点页面。另记录 5 个非地点页面：地牢谜题房间说明、中心岛村民、官方建筑、商店、锻造所讨论页。
- 所有中文译名均检查无拉丁字母；专名采用中文音译或意译。译名是本项目的翻译，不宣称均为社区标准。其他已有人工译文没有批量覆写。

原始网页快照、分类分页名单保存在 `translation-state/locations/`。`tools/location_catalog.py` 可从快照重新提取；`tools/location_translation_data.py` 校验覆盖并生成三份词典。地点总表本身可能未收录所有临时房间和新区域，因此此数量描述已核对的 Wiki 覆盖，不是永久不变的全服总数。

## 本轮接入的显示规则

- 地点完整名称与地点图标行优先于通用翻译；不在玩家聊天或任意句子中做模糊替换。兼容服务器在地点名中插入的不可见填充字符。
- 现实日期按服务器提供的月/日/年改写：`10/17/26 m66CS` → `2026年10月17日 m66CS`。日期随服务器变化，不硬编码当天；服务器编号保留。
- 十二个月：初春、仲春、暮春；初夏、仲夏、暮夏；初秋、仲秋、暮秋；初冬、仲冬、暮冬。每月 1st–31st → 1日–31日。依据[时间系统](https://hypixelskyblock.minecraft.wiki/w/Time_Systems)，并按用户要求使用这些中文显示格式。
- 用户已确认 `5:00am` 等时间保持原样。`Objective` → `任务`，方向箭头保留；截图任务 `Talk to the Bartender` → `与酒保交谈`。
- 翻译在已有显示钩子执行，保留源组件、图标、数值、服务器信息和交互样式；未修改服务端计分板。

## 钱袋下方内容调查

下半区不是固定菜单，会受所在岛屿、活动、进行中的任务和用户其他模组影响。以下是已找到依据的内容，位置和完整逐行格式仍需实机采样：

| 内容 | 依据 | 下一步处理 |
|---|---|---|
| 任务标题、任务描述、方向箭头 | 用户的酒保任务截图 | 本轮处理标题及截图中的酒保任务，其他任务描述逐项补充 |
| 比特余额 | [官方更新记录的比特计分板修复](https://hypixel-skyblock.fandom.com/wiki/Changelog/2024/April_24) | 保留余额，补数字模板与实际行样式 |
| 花园铜币 | [Copper 的 Display 段落](https://hypixelskyblock.minecraft.wiki/w/Copper)明确说明花园计分板显示 | 按场景补充，保留余额 |
| 讨伐任务与召唤进度 | [Slayer](https://hypixelskyblock.minecraft.wiki/w/Slayer)说明当前任务及进度显示于计分板 | 需要收集召唤、首领存活、完成和失败等状态 |
| 雅各布农业比赛排名与收集差距 | [玩家实际侧栏格式反馈](https://hypixel.net/threads/jacob%C2%B4s-contest-scoreboard-bug-in-garden.5342422/)；[比赛条目](https://hypixelskyblock.minecraft.wiki/w/Jacob%27s_Farming_Contest) | 后续实机确认当前版本的逐行格式 |
| 节日活动统计，如守卫杰瑞工坊伤害 | [活动说明](https://hypixel-skyblock.fandom.com/wiki/Defend_Jerry%27s_Workshop) | 后续补活动进度、倒计时等格式 |

矿区事件/风向、寒冷/热量、地牢探索与队伍、裂隙时间/微粒等也应列入下一轮场景检查。尚未完成这些区域当前版本的侧栏逐行采样，不能据此宣称已全部翻译。自定义计分板模组还能加入银行余额、宠物、神药、灵魂流等自选项目；这些不应混算为服务器默认钱袋下方的固定项目。

## 本轮穿插的 Bazaar 反馈

用户指定的 Spooky→万圣节、Winter→圣诞节、Minerals→挖矿节、Coupons→树岛兑换券、Mythological→挖宝生物、Fishing Festival→钓鱼节、Jerry Boxes→杰瑞礼盒、Diaz→股票兑换物、Hoppity's Hunt→复活节、Year of the Seal→海豹年、Feast→丰收节，只应用于 Events 商品分组提示，不改变季节等其他语境。中文标题已先被翻译的情况也能识别。

新增 Power Stones、Reforge Stones、Shards 分组说明；物品名称按用户要求改为亡灵维生素、古怪油画、古怪油画礼包。词典与逻辑仍为开发版本，Java 修改需要重启客户端，未发布最终包。

后续同轮反馈也已包含：仆从升级/储物箱/压缩器分类、终极附魔分类说明、Currently viewing! 提示，以及 Slayer / Slayers 统一为“杀手”。本文件上文调查中使用的“讨伐”描述游戏机制，实际显示术语以最新的[用户指定术语](用户指定术语.md)为准。
