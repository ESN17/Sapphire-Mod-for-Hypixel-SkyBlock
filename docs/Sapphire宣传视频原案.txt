Sapphire 宣传视频原案
建议成片时长：2 分 30 秒至 3 分钟；横屏 1080p，实录为主。
标题参考：《看得懂，才玩得爽：Sapphire 空岛汉化模组》

00:00—00:15 开场：信息太多，看不懂怎么办？
画面：物品描述、地牢通知、Tab 信息快速切换；同一画面展示开启汉化前后的对比。
旁白：在 Hypixel SkyBlock 里，一件装备能写半屏说明，一场地牢能刷满聊天框。Sapphire 想做的，就是让这些信息更容易看懂。
字幕：Sapphire · Hypixel SkyBlock 中文汉化

00:15—00:45 物品、菜单与系统通知
画面：悬停武器、宠物携带物、碎片；打开拍卖行、山峦之心；展示计分板和地牢奖励。
旁白：物品名称与描述、菜单、系统通知、计分板和 Tab 信息，都可以使用中文阅读。数值、颜色和玩家名字会保留；物品译名按词库统一。
字幕：演示当前已收录内容；不要使用“所有文本 100% 汉化”的宣传语。

00:45—01:05 随时核对英文
画面：聊天译文上悬停出现“英文原文”；右键复制后粘贴到一个本地文本框。展示默认英文、按住 Ctrl 查看中文的设置。
旁白：不确定某句话原本怎么写？鼠标放上去就能查看英文，右键还能复制。也可以保留英文界面，需要时按住 Ctrl 查看中文。
字幕：左键原有操作保留 · 原文可追溯

01:05—01:30 词库与个人修改
画面：/sapphire 打开设置，搜索一个物品，预览并修改本地译文；展示词库更新通知。
旁白：词库更新会自动检查。你也能在游戏内查找、预览和调整自己的译文。物品汉化发生在显示时，不修改服务器发来的物品数据。
字幕：官方词库同步 · 本地编辑

01:30—02:00 教程问答（本轮新增，发布前使用实际验证画面）
画面：输入 /sahelp 如何提高光泽宝石的掉落概率？显示“[SAPPHIRE] 正在思考中……”，再展示实际 API 回复及 Wiki 来源。
旁白：遇到不懂的玩法，也可以直接提问。Sapphire 会检索 Wiki 资料，再交给你配置的 API 整理答案。已收录物品会显示中文名和英文名，方便继续查资料。
字幕：需要配置 API；回复依赖 Wiki 快照和模型，关键数值请核对来源。
拍摄注意：使用实时生成的回答，不把示例中的“2.3 倍”写成固定承诺。

02:00—02:20 常用模组兼容
画面：SkyHanni 与 Odin 已覆盖的设置页、HUD、通知；切换汉化开关。
旁白：Sapphire 也在补充常用模组的汉化。安装对应模组时启用兼容；没有安装，也能正常使用 Sapphire。你看到的是中文，其他模组读取的原始数据仍然保留。
字幕：覆盖持续扩充 · 以实际支持版本和测试结果为准

02:20—02:45 结尾与下载
画面：Sapphire 图标、下载页、GitHub 页面，最后停留 5 秒。
旁白：欢迎体验 Sapphire，也欢迎反馈漏译和不通顺的地方。让我们一起把空岛里的每一句话，翻译得更清楚。
