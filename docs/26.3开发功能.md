# Minecraft 26.3 开发功能

开发版本使用 Minecraft 26.3、Java 25、Fabric Loader 0.19.5、Fabric API 0.165.0+26.3。原 26.1.2 全工程备份位于 `backups/Sapphire-full-26.1.2-20261030.zip`；公开源码快照位于 `exports/Sapphire-dev-0.0.4-GitHub`。私人备份不可公开上传。

## 物品提示性能与 Ctrl

提示框缓存最多保留 128 组结果，区分物品 ID、原始文本、颜色样式、菜单、窗口宽度、开关及词典版本。词典或资源重载时清除缓存；返回的显示组件独立复制，不修改服务器物品。未翻译收集对重复物品做有上限的去重。

`/sapphire` 的“默认英文 / Ctrl 中文”默认关闭：

- 关闭：平时中文，按住任一 Ctrl 查看英文。
- 开启：平时英文，按住任一 Ctrl 查看中文。

此选项控制物品和菜单按钮的悬浮提示框；聊天、计分板和 Tab 列表继续由各自的翻译开关控制。

## 中文聊天自动英译发送

进入 `/sapphire api`，配置现有服务商、完整请求地址、模型和 API Key。在“范围与限速”开启“在线翻译”及“中文聊天自动英译并发送”。Sapphire 总开关、聊天开关和生效环境条件仍适用。

普通聊天包含中文时，按 Enter 后先在后台翻译，成功才通过 Minecraft 的正常聊天发送路径发出英文。英文消息保持原流程；以 `/` 输入的命令不拦截。队列按顺序处理，不自动重试，不合并相同消息。失败、超时、限速或过长译文不会自动发送原文；聊天栏会提供可点击恢复的原文。离开服务器后取消旧连接的待发送任务，防止发到另一个服务器。

“提示词”页面可以切换收到消息的中文提示词和发送聊天的英文提示词。两者独立保存。选中的消息会发给配置的 API，费用取决于服务商。请求超时为 5–60 秒；收、发两个方向分别受设置的每分钟次数限制。功能默认关闭。

## 完整词典编辑器

`/sapphire` → “修改翻译”，或 `/sapphire edit`：

- 搜索文件名、物品 ID、英文或中文。
- 浏览物品名称、描述、附魔、菜单、系统通知、共享段落、Sapphire 独立重译与 Wiki 补充词条。
- “预览效果”使用游戏字体和翻译渲染器生成样例；有采集样式时保留样式，变量和实际断行以服务器文本为准。
- 修改后“保存并生效”，后台保存并重建索引，完成后切换词典。
- 保留变量，阻止覆盖已被其他编辑修改的条目。保存前自动备份原文件到 `config/sapphire/translation-edits/`，保留来源与许可元数据。

词典重载期间继续使用旧词典；加载失败时保留旧的可用索引。界面不会修改资源来源、许可、物品 ID 等非译文字段。

同一原文可能存在于多个场景，编辑时请根据词典文件和物品 ID 选择对应条目。编辑器保留原有匹配优先级；动态模板的修改会同步更新对应的固定数值样例。

服务器同步不在这次实现范围。当前译文仍保存在本机，客户端没有上传译文的账号或密码设置。
