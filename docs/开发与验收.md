# Sapphire 开发与验收

目标保持 Minecraft **26.1.2** / Java **25** / Fabric Loader **0.19.5** / Fabric API **0.155.3+26.1.2**。Loom 在本机解析为 1.18.4。代码使用该版本未混淆的 Mojang 类名，未复制旧 Yarn 注入点。

## 本地验证方式

```powershell
.\gradlew.bat build
python -m unittest discover -s tools -p "test_*.py" -v
.\gradlew.bat runClient -PsapphireSmoke
```

`sapphireSmoke` 只用于开发测试：启动独立开发客户端，强制加载并审核 Mixin，构造无服务器来源的测试物品，检查真实 Fabric Tooltip 回调、名称/Lore 翻译、原文回退、关闭功能和数据不变性，随后退出。无需正版登录，不连接 Hypixel。普通启动不运行测试；是否忽略翻译的环境限制由 `forceTranslation` 控制，新配置默认开启。

构建产物为 `build/libs/sapphire-1.0.0.jar`；不要安装 `-sources.jar`。详细 Java 测试报告在 `build/reports/tests/test/index.html`。启动日志中的 `SAPPHIRE_SMOKE_OK` 表示功能检查通过，单纯看到窗口或 `compileJava` 成功不代表此项通过。

## 版本签名与显示入口

签名经本地 26.1.2 JAR 的 `javap`、Loom `genSources` 和真实客户端 Mixin audit 核实。

| 文本 | 入口 | 数据处理方式 |
| --- | --- | --- |
| Tooltip | Fabric `ItemTooltipCallback#getTooltip(ItemStack, Item.TooltipContext, TooltipFlag, List<Component>)` | 只替换回调列表中的显示组件 |
| 手持物品提示 | `Gui#extractSelectedItemName(GuiGraphicsExtractor)` 中的 `ItemStack#getHoverName()` | 修改局部表达式结果 |
| 容器标题 | `AbstractContainerScreen#extractLabels(GuiGraphicsExtractor,int,int)` 读取 `title` | 修改局部字段读取结果 |
| 计分板 | `Gui#displayScoreboardSidebar` 及其 `$1` lambda 的 `PlayerTeam.formatNameForTeam` | 在宽度计算前生成译文，不改 Objective/Team/分数 |
| Action Bar | `Gui#extractOverlayMessage` | 只拦截显示字段读取 |
| Title/Subtitle | `Gui#extractTitle` | 两个独立字段，各自配置开关 |
| Boss Bar | `BossHealthOverlay#extractRenderState` 中 `LerpingBossEvent#getName()` | 在宽度计算前生成显示副本 |
| 系统聊天 | Fabric `ClientReceiveMessageEvents.MODIFY_GAME` 非 overlay 分支 | 仅 chat 字典精确白名单；不注册玩家聊天事件 |

Mixin `defaultRequire=1`，签名变化会明确失败，不会静默宣称功能正常。没有全局字体渲染覆盖，没有改 ItemStack 的 getter 返回值，没有修改网络包。`ItemStack#set` 只出现在隔离的开发测试夹具中，正常翻译路径不调用。

## 模块职责

- `Sapphire`：客户端生命周期、默认配置安装、命令和回调。
- `TranslationManager`：严格 JSON、原子词典快照、预编译模板、匹配优先级、4096 项有界 LRU 缓存。词典损坏后保留上一份有效词典。
- `TextTranslationEngine`：有效样式展开、变量/图标区间复制、双语样式对应和安全回退；ClickEvent/HoverEvent/Insertion 的载荷不翻译。独立子组件和换行可分别翻译。重铸前缀与基础名称分别替换，前后装饰保留。
- `LoreTranslationEngine`：匹配连续原文段落及数字占位符，在显示副本中合并；调用原版 `Font.getSplitter().splitLines` 重新换行，再按原样式重建组件。收集路径复用相同段落匹配，避免把已翻译段落误报为未翻译。
- `NeuRepositoryManager` / `ItemIdResolver`：NEU 索引、SkyBlock ExtraAttributes、宠物/附魔书变体和明确别名。`itemid` 不是 SkyBlock ID。
- `ItemTranslationService`：名称锚点替换、Lore 翻译、物品栏/容器收集。
- `SkyBlockContext`：Hypixel 域名边界 + 服务端 brand + 计分板标题 + 网站行 + 钱袋/地点信号，连续确认环境。与原版一致优先读取玩家队伍颜色对应的侧栏，再回退普通侧栏。世界/连接变化立即重置。强制翻译不改变检测结果，也不绕过收集门槛。
- `CollectionPolicy` / `UntranslatedCollector`：人工审核白名单、有界队列、每键一秒节流、后台聚合、30 秒批量写入、退出刷新。默认最多 2000 条记录、512 个待处理事件、16 MiB 收集目录、单文件 256 KiB；每条最多 64 个候选，每候选最多 3 个样本。
- `dictionary_tool.py`：本地/主动 GitHub 同步、变更清单、生成待译文件、扫描统计、导出导入、无覆盖合并和校验。

英文 NEU 索引来自官方仓库，其来源、commit 和同步时间随索引保存；MIT 许可证与索引一起打包。游戏运行时不请求 NEU、不调用在线翻译，不依赖 NEU Mod。

## 已有自动覆盖

- ID 读取不改变原始 NBT；未知 ID、宠物损坏数据、多附魔书安全回退。
- 物品专属 / 通用 / 模板优先级；空值和未知文本回退。
- 数值、符号、千位分隔符、小数、百分比；占位符不一致和重复 JSON 键拒绝。
- 不同比例的中英文长度、数字样式、传统 § 代码、前缀/星级、嵌套组件、换行、交互事件保留。
- 重载失败保留旧数据，成功重载使缓存失效。
- 关闭/环境不明/不安全/已完成观察不产生记录；动态值和重复观察不造成无限文件。
- 20,000 次高频匹配/观察在测试时间限制内完成；缓存有界，观察循环不产生同步磁盘写入。
- 收集记录重启恢复、译文保留、损坏文件保留、记录上限、退出刷新。
- Python 增量同步、字段异常、重复键、模板校验、导出防覆盖、导入冲突保留、未知 ID 和路径处理。

## 需要 Hypixel 实机验收

这些检查不能由离线启动替代，尚未宣称完成：

1. 使用正版账号进入 Hypixel SkyBlock，执行 `/sapphire status`，确认检测为 true；离开 SkyBlock 或切换世界时不应沿用旧状态。
2. 普通/重铸/星级/宠物/附魔书分别在背包、箱子、拍卖行、集市悬停；确认名称、Lore、稀有度、图标、样式和动态值。
3. 选中物品查看快捷栏上方名称；比较 Tooltip 与原始组件，检查其他 Mod 的物品搜索/识别不受影响。
4. 查看 GUI 标题和虚拟菜单物品、聊天系统消息、计分板、Action Bar、Title/Subtitle、Boss Bar；留意宽度、重复翻译和颜色。
5. 发送普通聊天、私聊、公会/队伍聊天，确认内容不被收集；查看玩家自定义物品文字不落盘。
6. 开启收集游玩，导出填写一个新词条，导入并 `/sapphire reload`；确认立即生效且旧中文没有被覆盖。
7. 使用高频变化的计分板和大背包，观察帧率/内存和磁盘；离线基准不是实机 FPS 承诺。
8. 与你实际使用、且支持 26.1.2 的其他 Mod 一起测试；未测试的 NEU、SkyHanni、Skytils 共存情况不作保证。

## 当前边界

这是可以安装测试的实现，不等于全量汉化已经完成。中文覆盖由本地词典决定。

- 无法明确映射的多色整句和复杂组件保留原文；不会按长度猜样式。物品 `styleMappings` 可明确对应中英文片段，动态数值/图标复制完整原样式；映射歧义仍回退。复杂可点击区域可只翻译独立子组件。
- 特殊药水、符文、未覆盖的变体不猜 NEU ID。无 ID 物品只允许明确 GUI 字典匹配；其他名称保留英文。
- 服务器环境检测采用保守组合，协议/计分板变化可能产生假阴性；不明确时停止收集。新配置默认强制翻译，仍按词典和分类开关显示；执行 `/sapphire force off` 后，环境不明确时也停止翻译。
- 未知系统消息和未审查的 GUI/HUD 字符串不会自动保存。NEU 与 collection-rules 以外的玩家可控文字被排除。这限制自动发现范围，但避免误收私人文字。
- 自定义容器子类若覆盖了原生标题绘制，可能不经过当前容器标题钩子。
- 收集文件损坏时保留原文件并报告，不自动覆盖修复；可先备份，再移走损坏文件后重试。
- 调整队列/磁盘/条数上限后需重启客户端；普通翻译词典和模块开关可热重载。
- 网络同步、导出、导入是用户主动运行的 CLI；不存在运行时自动下载或上传。

后续扩充应基于实机观察逐项增加安全来源规则和变体映射，并补对应回归测试。

## 主菜单、拍卖行与 Bazaar：2026-10-17

这一阶段增加 765 条上下文规则（含共用按钮和格式变体）、66 个菜单标题匹配形式。规则数不等于已覆盖的真实界面数量。三个上下文分别是 SkyBlock 主菜单、拍卖行和 Bazaar。

资料依据包括 [主菜单](https://hypixelskyblock.minecraft.wiki/w/SkyBlock_Menu)、[拍卖行](https://hypixelskyblock.minecraft.wiki/w/Auction_House) 与 [Bazaar](https://hypixelskyblock.minecraft.wiki/w/Bazaar) 的公开页面。测试保存了 26 份主菜单与拍卖行按钮样本的原始颜色和换行；Bazaar 的动态数量、单价、订单进度由独立构造的测试样本验证，尚未以当前在线界面逐页验收。公开资料可能落后于服务器。

实现仅修改显示组件：容器标题保持原始值，服务器物品数据和点击逻辑不修改。通过实际容器槽位归属区分菜单按钮与玩家背包；菜单开关独立于物品与 Lore 开关。系统不读写搜索输入框，不猜译玩家名、搜索词和未知商品名称，不执行购买、卖出、出价或取消订单。

字典位于 `translations/gui-menus.json`：顶层 `loreParagraphs` 为共用规则，`menus` 内含上下文 `id`、`titles` 标题模板及各自 `loreParagraphs`。每条规则保留原始数字占位符；颜色对应写入 `styleMappings`。词典工具支持校验、无覆盖合并，错误文件重载失败时保留上一份快照。构建测试不作为最终发布。

在线验收优先检查：

1. 主菜单的技能、收藏、仓库、宠物和设置按钮标题及说明。
2. 拍卖行浏览、稀有度筛选、排序、价格和手续费；检查玩家名称与搜索内容原样显示。
3. Bazaar 分类、立即买卖、创建买卖单、订单状态与进度；只观察提示框即可，不需要真的交易。
4. 分别关闭“菜单”“物品名称”“物品描述”，检查独立开关与 Ctrl 英文预览；打开菜单时玩家背包不误用菜单规则。

设置界面改版、其他菜单以及全部聊天/HUD 覆盖不属于本轮完成范围。

本轮验证结果：Gradle 完整构建通过，Java 376 项通过、1 项可选跳过；Python 工具 34 项通过。离线客户端在 `build/sapphire-gui-smoke-20261017/logs/latest.log` 产生 `SAPPHIRE_SMOKE_OK`，涵盖实际字体换行、菜单开关独立性、Ctrl 英文预览以及源组件不变性。尚未完成当前 Hypixel 在线界面的逐页验收。机器可读结果见 `translation-state/gui/report.json`。
