# 死亡、怪物与海怪名称翻译

适用于当前 Minecraft 26.3 开发工程。本次修改不生成发布 JAR。

## 范围

- `death-messages.json`：278 条完整消息规则，包含本人及其他玩家死亡、怪物击杀、环境死亡、地牢幽灵、断线、硬币损失、存钱罐损坏、复活和死亡标题。包含已见格式及兼容变体，不代表 278 种不同死因。
- `entity-names.json`：604 个名称及别名条目，包含普通怪物、地牢怪物、杀手怪物、海怪、裂隙生物及部分历史名称。指定的人名保持原文，例如 Jerry、Bonzo、Scarf、Necron。数字、罗马等级、血量及图标不改变。
- `creature-messages.json`：108 条规则，包含从 85 个海怪页面提取的 97 条钓起/战斗提示，以及通用钓起、双钩、击杀、海怪数量上限提示及图鉴族群名称。
- `entity-labels.json`：NPC 职业、点击提示及怪物修饰前缀。NPC 人名不做全局词语替换。
- `entity-menus.json`：海怪图鉴、生物图鉴等菜单使用同一套名称。

头顶名称支持普通实体名称标签、盔甲架名称标签和 Text Display 文本显示实体。Mixin 已按 26.3 的实际类签名编写，只替换当前帧的渲染数据；不修改实体自定义名称、同步数据、物品数据或服务器内容。玩家实体的名称标签排除在外。

名称匹配限定为完整名称或带等级、前缀、血量的标签。聊天中使用完整句式，不在玩家聊天的子组件中扫描新增死亡/海怪规则。未登记的怪物名称保留原文，死亡原因仍可翻译。

## 使用

Java 渲染代码有变更，需要退出并重新运行开发客户端。当前正在运行的旧客户端不会自动加载新代码。

在 `/sapphire` 中可用“生物与 NPC 标签”单独切换头顶名称汉化。关闭后立即显示原文。聊天和首领栏分别遵循各自原有开关。

在 `/sapphire edit` 搜索英文或中文名称、死亡原文，即可预览并修改这些新词典。保存后沿用原有备份和异步重载机制。所有词典独立于 Java 代码；已有物品及社区翻译文件没有被重写。

## 性能设计

- 名称标签有独立的 512 条有界缓存，命中时不重新扫描规则。缓存键包含原文、完整样式、词典对象与词典修订号。
- 血量或颜色变化会使用新的键；词典重载会自动失效，不会一直显示旧名称。
- 文本显示实体的换行布局另有 128 条缓存，包含字体和行宽；资源重载与断线时清空。
- 缓存返回独立的组件树，避免调用方改动污染后续显示。未知名称也缓存未匹配结果。
- 渲染路径没有网络请求、磁盘读取或对八千多个物品描述的遍历。
- 单元测试覆盖重复命中、样式变化、缓存上限、词典更新、未知名称、组件不可变及原始数据保留。开发客户端烟雾检查另外测量名称标签和物品提示的重复调用耗时；这些局部耗时不等于服务器内的整体 FPS。

## 本次验证结果

2026-10-30 最终构建：506 项测试，0 失败、0 错误，2 项原有可选测试跳过。没有生成新 JAR。

独立 26.3 离线客户端通过 Mixin audit、名称翻译、Text Display 换行布局、关闭开关恢复原文、缓存失效和组件不可变检查。名称标签预热后重复 10,000 次，平均约 2.49 微秒；首次样例约 1.87 毫秒。原有物品提示重复 500 次平均约 23 微秒。结果仅为这台机器上的局部调用测量，不是 Hypixel 多实体场景下的 FPS 保证。

五个新增词典已放入 `run/config/sapphire/translations/`，原有文件没有被覆盖。构建日志为 `build/death-creature-final.log`，客户端验证日志为 `build/death-creature-verification.log`，文件哈希和统计为 `build/death-creature-verification.json`。重启开发客户端生效。
