# 全量物品翻译与恢复

本轮来源是本地 NEU 快照的 8,937 个 ID；稀有度、宠物等级变体和附魔等级会分别计入 ID 数量，不等于 8,937 种不同基础物品。

用户术语和专有名词规则在 `tools/translation_policy.json`。DeepSeek 只接收公开物品显示名称、描述和格式提示。请求不包含 NBT、账号凭据或玩家数据。`deepseek.local.json`、缓存、账单用量记录和备份均不打入 JAR。

## 可恢复步骤

```powershell
python tools/bulk_translate.py prepare
python tools/bulk_translate.py translate --workers 12
python tools/bulk_translate.py status
python tools/bulk_translate.py stage
$env:SAPPHIRE_BULK_AUDIT='true'
.\gradlew.bat test --tests '*BulkTranslationAuditTest'
```

`status` 的 `text_ready_items` 仅表示文本齐备。实际渲染通过数量以 `translation-state/audit-result.json` 的 `passedItems` 为准。先等 `stage` 完成，再运行审计；不要同时改动暂存词典。启用审计环境变量后，Gradle 会跟踪暂存词典并重新执行检查。

失败单元写入 `translation-state/repair-jobs.json`。可以针对这些单元调用 `tools/repair_bulk_styles.py`，然后重新暂存和审计。`tools/review_bulk_exceptions.py` 包含本轮特殊描述的人工修订。所有数字占位符、符号和指定术语都必须通过本地检查。

`tools/enrich_style_mappings.py` 仅辅助补齐已有双语颜色词组，不代表人工认可；运行后必须重新审计。不同单元的数字占位符不可当作可共享术语。

## 安装与保护现有词典

本次用户明确要求修订旧译文，因此提供专用迁移：

```powershell
python tools/install_bulk_translations.py
.\gradlew.bat build
```

安装要求全量审计通过，并核对暂存词典的 SHA-256。它先备份全部已有目标文件，然后安装到内置资源、编辑工作区和开发客户端三处；保留额外的洗练加成和宠物动态规则，并更新指定术语及标点。备份在 `translation-state/pre-bulk/`。不应把这个专用迁移脚本用于覆盖后来新增的手工审校结果。

游戏启动和 `dictionary_tool.py merge` 仍只补充缺失或空白内容。升级另一个启动器实例时，先备份该实例词典，再明确选择迁移；仅替换 JAR 不会覆盖已经存在的 JSON。

本轮修改了渲染代码，需要重启客户端。之后仅改 JSON 时执行 `/sapphire reload` 即可。

## 验证边界

自动检查验证 JSON、指定术语、占位符、符号、NEU 参考组件的翻译渲染，以及源组件不被修改。回归测试另检查具体颜色、粗体、动态传送距离、宠物等级、洗练加成和安全回退。

这些检查不证明每句机器翻译都达到人工润色水准，也不覆盖服务器未来改动、未知变体或其他 Mod 的所有组合。保留 Kat 等 NPC 名称及原有品牌文字是有意行为；没有中文的名称会被字典工具列为人工复核提示。

普通颜色按语义片段继承。字母逐个变色的装饰性彩虹词，只有明确提供整词映射时才按原调色板分配到中文字符，中文和英文字符数量可以不同；这不用于普通多色句。
