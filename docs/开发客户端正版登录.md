# IntelliJ IDEA / runClient 正版登录

当前项目使用 **Loom 1.18.4 自带的微软登录功能**，不添加第三方登录 Mod，开发版本为 Minecraft 26.3 和 Java 25。

## 一键登录并启动

在项目目录的终端运行：

```powershell
.\tools\login-dev-client.cmd
```

脚本先运行 `microsoftLogin`，认证成功后再运行 `runClient`。如果认证失败，脚本停止，不继续启动客户端。

也可以分步运行：

```powershell
.\gradlew.bat microsoftLogin --console=plain
.\gradlew.bat runClient --console=plain
```

1. 登录任务会在你的终端显示微软验证页面地址和一次性设备码。
2. 由你本人打开该微软页面，输入设备码，登录拥有 Minecraft Java Edition 的微软账号并完成授权。设备码只在你自己的终端和微软页面之间使用，不要发到聊天里。
3. 终端确认 Minecraft 登录成功后，`runClient` 使用该账号启动开发游戏。
4. 进入“多人游戏”，添加 `mc.hypixel.net` 并连接；进入 SkyBlock 后执行 `/sapphire status`，确认环境检测。

无需手动填写 `--accessToken`、密码、UUID 或刷新令牌。不要把这些信息写到 Gradle、IDEA 配置或聊天里。

## 在 IntelliJ IDEA 中运行或调试

重新加载 Gradle 项目，在运行配置列表选择项目已提供的 **Sapphire Login and Client**。它依次执行 `microsoftLogin` 和 `runClient`。在 IDEA Run 窗口按提示完成浏览器认证即可。

也可以通过 Gradle 工具窗口分别搜索并运行 `microsoftLogin` 和 `runClient`。

登录成功后，从 Gradle 工具窗口运行 `runClient`。也可以新建 **Gradle** 类型运行配置：

| 配置项 | 值 |
| --- | --- |
| 名称 | Sapphire Microsoft Login |
| Gradle 项目 | 当前 Sapphire 项目 |
| Tasks / Run | `runClient --console=plain` |
| Gradle JVM | Java 25 |

需要调试时，从该 Gradle 任务配置使用 Debug。应使用 Gradle `runClient` 入口；Loom 的认证参数是在任务执行时注入的，旧的直接运行 `Main` / `KnotClient` 的 Application 配置不会自动使用此认证流程。

本版 Loom 没有 `genIntellijRuns` 任务，不需要执行旧版本教程中的该命令。

## 登录配置与本地缓存

项目已将 `microsoftLogin`、`microsoftLogout` 和 `runClient` 默认配置为名为 **sapphire** 的认证 profile，与其他项目的默认账号分开。

Loom 把账号持久化数据加密存储在 Gradle 用户缓存中，并由操作系统保护密钥。默认 Windows 路径类似：

```text
%USERPROFILE%/.gradle/caches/fabric-loom/microsoft-auth-sapphire.json
```

本项目代码不会读取、显示或打包该文件。文件名模式也已加入 `.gitignore`，以覆盖自定义 Gradle 用户目录放在项目内部的情况。启动时由 Loom 刷新游戏会话。不要上传账号缓存、密钥、整个 Gradle 用户目录或含认证启动参数的调试日志。

不要为认证启动添加 `--info`、`--debug` 或 `--scan`；只使用默认日志级别。Gradle 的详细进程日志可能包含启动参数。

更换账号或清除本地登录：

```powershell
.\gradlew.bat microsoftLogout
.\gradlew.bat microsoftLogin
```

`microsoftLogout` 只清除 Sapphire profile 的本地账号和对应受保护密钥，不会清除其他项目的 profile；它也不是微软账号的全局撤销授权。

## 离线开发与测试

```powershell
# 不读取或刷新微软账号的开发客户端
.\gradlew.bat runClientOffline

# 自动冒烟测试：审核 Mixin/Tooltip 后退出，明确禁用微软认证
.\gradlew.bat runClient -PsapphireSmoke

# 常规构建和单元测试不会触发登录
.\gradlew.bat build
```

## 常见问题

- **无法获得设备码**：检查微软登录、Xbox Live 和 Minecraft Services 的网络连接，然后重新运行登录任务。
- **账号没有 Minecraft 游戏资料**：确认所用账号拥有 Java Edition，并已创建 Java 版档案。
- **进入 Hypixel 提示会话无效/无法验证用户名**：关闭开发客户端，执行 `microsoftLogout`、`microsoftLogin`，再运行 `runClient`。
- **看到离线 Player 身份**：确认从 Gradle `runClient` 启动，且登录使用 sapphire profile。Loom 在后续刷新失败时可能回退离线启动，因此看到主菜单不代表认证成功。
- **多人游戏受账号限制**：在微软/Xbox 官方账号设置中处理对应限制。

构建与离线客户端测试只能验证配置和运行环境；微软授权与 Hypixel 连接必须在本人完成认证后确认。
