# NPC 对话与聊天实时翻译

用户于 2026-10-17 提出，已实现五服务商设置及异步聊天翻译。默认关闭，需在自己的游戏实例中填写密钥、检查模型、选择范围并保存后启用。

- 在 Minecraft 的 `config/sapphire/` 目录中提供 API 配置，支持 ChatGPT、Claude、DeepSeek、Kimi、GLM。
- 配置项包括服务商、API 地址、模型、API Key；为不同服务商提供协议适配，不假设所有接口相同。
- 提供独立、可编辑的翻译提示词；沿用既有中文术语，保护玩家名、命令、数值和格式。
- 翻译 NPC 对话和聊天框收到的内容；只更新本地显示，不自动向游戏聊天发送消息。
- API Key 仅保存本地，不写入日志、词典、构建产物或提交记录。
- 异步请求、缓存、限速、超时和失败回退，避免阻塞游戏线程；保留查看原文的入口。
- 在启用界面说明所选聊天内容将发送至配置的 API 服务，并提供翻译范围开关。

## 使用

输入 `/sapphire` → **API 与提示词**，或直接 `/sapphire api`。页面分为“服务商”“提示词”“范围与限速”。五家各自保存完整请求地址、模型 ID 和密钥；切换服务商不会清空其他家的设置。

1. 选择服务商，填写自己的 API Key，按账号权限修改模型 ID。地址为完整请求路径，不是只有域名的 Base URL。
2. 在“提示词”页输入多行翻译要求，最多 8000 字符。原文由程序另行传入，无需写 `{text}`。
3. “测试连接”只发送固定测试句，不读取聊天，可能产生一次 API 调用费用；测试成功不等于保存或开启。
4. 在“范围与限速”开启在线翻译，选择 NPC、玩家聊天（包含私聊）或未翻译系统消息，点击保存。取消或 Esc 放弃修改。

总开关默认关闭。默认范围为 NPC；玩家聊天和系统消息需分别打开。范围通过已知 Hypixel 聊天前缀和 Fabric 消息类型识别，非标准服务器前缀可能需要后续补充。Sapphire 的总开关、聊天开关和环境限制也继续生效。

原文立即显示；成功后补充 `[译]` 行，保留说话者前缀，悬停译文查看完整原文。原消息的颜色和交互不变；补充译文使用统一白色，不能可靠推断的语义颜色不臆造。不会代替玩家发言、执行命令或修改服务器物品。已被本地词典翻译的系统消息不再请求 API。

## 文件

均位于当前游戏实例的 `config/sapphire/`：

- `api.json`：开关、服务商、各家地址和模型、频率与超时。
- `api-keys.local.json`：各家密钥，本机明文保存；界面掩码显示，不包含在普通配置、词典、日志和构建资源中，分享配置时排除此文件。
- `translation-prompt.txt`：可在游戏内或文本编辑器中编辑。外部修改后 `/sapphire reload` 生效。

## 协议依据（2026-10-17 核对）

| 选项 | 接口 | 官方依据 |
|---|---|---|
| ChatGPT / OpenAI | `/v1/responses`，Bearer；`instructions` 与 `input`，`store:false` | [OpenAI 文本生成](https://developers.openai.com/api/docs/guides/text) |
| Claude | `/v1/messages`，`x-api-key` 和 `anthropic-version:2023-06-01` | [Messages API](https://platform.claude.com/docs/en/api/messages/create) |
| DeepSeek | `/chat/completions`，Bearer，读取最终 `content` | [DeepSeek 首次调用](https://api-docs.deepseek.com/) |
| Kimi | `/v1/chat/completions`，Bearer | [Kimi Chat Completions](https://platform.kimi.com/docs/api/chat) |
| GLM / 智谱 | `/api/paas/v4/chat/completions`，Bearer | [智谱官方 SDK](https://github.com/MetaGLM/zhipuai-sdk-python-v4/blob/main/README_CN.md) |

预填模型只是可编辑起点，不保证任何账号都可用：OpenAI 为 `gpt-6-luna`，Claude 为 `claude-haiku-4-5`，DeepSeek 为 `deepseek-flash`，Kimi 为 `kimi-k2.5`，GLM 为 `glm-4`。模型可用性和退役由服务商控制。Kimi 中国/国际平台密钥与地址需对应；可在地址栏改成自己的完整接口。ChatGPT 应用订阅不作为 API Key 使用。

## 运行限制与验证

单后台工作线程，最多 16 个排队请求，内存缓存 128 条；默认每分钟 20 次、超时 20 秒，可分别设置 1–60 次和 5–60 秒。不会自动重试；失败后短暂冷却，原文保留。断开连接、更换服务器、保存配置或重载会清空队列和缓存，取消进行中的请求，丢弃旧响应。聊天和译文不写入磁盘缓存。

数值、已知玩家名、链接和命令名称使用占位符保护，缺失、重复占位符或返回额外数字时拒绝显示译文。模型响应仅解析最终文本，不执行工具、不展示思考内容；超长响应、不完整结果及非法格式回退原文。HTTP 不跟随重定向，远程地址要求 HTTPS，本机回环地址允许 HTTP。

测试使用虚构密钥与本机模拟 HTTP 服务，验证五家请求结构、响应解析、错误处理、限速、缓存、取消和配置隔离。尚未用真实付费密钥调用五家服务，需由用户在设置页测试自己的账号。开发 UI 冒烟入口为 `-PsapphireApiSmoke`，使用独立运行目录，不连接游戏服务器、不发送 API 请求。
