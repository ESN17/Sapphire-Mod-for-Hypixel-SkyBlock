# 2026-11-02 display feedback

Changes in the 26.3 development project (no release JAR or server publication):

- Standard rank: deep blue `[` and `]` (`#0000AA`), white `SAPPHIRE`
  (`#FFFFFF`), standard Minecraft blue username (`#5555FF`). Developer ranks
  retain their existing red styling. Server-provided SkyBlock level colors are
  no longer overwritten, including the personal level line in Tab.
- Island visitor notification translates the sentence while retaining the
  visitor name, rank and click/hover metadata.
- Fire Sale announcements translate the title, stock, instructions and variable
  countdown. Item names use an exact imported-item lookup. Unlisted products
  remain English; known rules bypass online retranslation to prevent invented
  new names. Unlisted cosmetic item tooltips also bypass name fallbacks until
  NEU metadata and a reviewed item translation exist.
- Garden rare drops have a separate template for a variable numeric bonus plus
  icon. Tested integers, decimals and thousands separators; no Magic Find label
  is added to this format.
- NPC sale messages use exact item-library names, variable quantities and prices.
  The pre-existing wording was retained and its quantity style mapping repaired.
  Feastfungus resolves to 盛宴菌菇; Pretty Fly Vinyl resolves to 漂亮苍蝇唱片.
- Version support notices retain the actual version token, including multi-part
  and prerelease versions, and retain the Learn More link event.

Dictionary edits retain backups and upgrade hashes. Local working/runtime copies
are updated only when they still match the previous unedited baseline. No
existing custom dictionary is overwritten. Online dictionary publication and
release packaging remain separate user-requested operations.

Tests: `VisitorSaleGardenTest`, `SapphireRankTest`; optional mod compatibility
is documented separately in `skyhanni-compatibility.md`.
