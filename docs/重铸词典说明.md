# 重铸名称中文词典

核对日期：2026-10-16。按重铸名称去重，本次 NEU 快照包含 **136** 个：50 个基础重铸、86 个重铸石重铸。另兼容 22 个历史饰品重铸名称、7 个特殊显示别名，词典共 **165** 条。历史名称和显示别名不计入当前 136 个重铸。

来源：[NEU 基础重铸](https://github.com/NotEnoughUpdates/NotEnoughUpdates-REPO/blob/master/constants/reforges.json)、[NEU 重铸石](https://github.com/NotEnoughUpdates/NotEnoughUpdates-REPO/blob/master/constants/reforgestones.json)、[历史饰品重铸](https://hypixelskyblock.minecraft.wiki/w/Reforging/Accessory)、[特殊显示前缀](https://hypixelskyblock.minecraft.wiki/w/Reforging#Duplicate_Prefixes)。准确计数口径和文件哈希见 `reforge-sources.json`；数据可能随游戏更新变化。

译名为 Sapphire 自定译名，以简短、可读、不同重铸易区分为原则，并非官方中文名称。Heroic 采用用户指定的“英雄的”；Fabled 与 Legendary 分别为“传奇的”和“传说的”。

文件：`translations/reforges.json`。只对已识别 SkyBlock 物品、NEU 基础名称前完整匹配的前缀进行替换，不全局替换同名英文单词。物品基础名尚无中文时，仍可显示中文重铸前缀；颜色、星标及后缀保留。已有非空译文不会被合并覆盖。
